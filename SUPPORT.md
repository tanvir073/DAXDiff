# Getting help

- **How do I…?** Start with the [user guide](docs/user/README.md) and its
  [troubleshooting page](docs/user/troubleshooting.md). Setting up sign-in for an organisation is in the
  [administrator guide](docs/user/administrators.md).
- **Questions and ideas to discuss:** ask in [Discussions](https://github.com/tanvir073/DAXDiff/discussions).
- **Something does not work:** [open a bug report](https://github.com/tanvir073/DAXDiff/issues/new?template=bug_report.yml),
  or use **Settings → Report a bug** in the app, which fills in your version and operating system.
- **A new feature:** [request it](https://github.com/tanvir073/DAXDiff/issues/new?template=feature_request.yml).
- **A security problem:** report it privately, never in a public issue; see [SECURITY.md](SECURITY.md).

DAXDiff is maintained in spare time, so answers can take a few days. Never post tokens, passwords or confidential
model data; screenshots and logs can be cropped or edited first.
