# Fonts

Fonts of the Numberskills design system, embedded as WPF resources:

- **Bricolage Grotesque** (display), by Mathieu Triay. Static instance at weight 400, optical size 32.
- **Onest** (text), by Dmitri Voloshin. Static instances at weights 400, 500 and 600.

Both are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org) and have no reserved font names.
WPF cannot load the design system's variable WOFF2 files, so these TTFs were instanced from them with fontTools.
